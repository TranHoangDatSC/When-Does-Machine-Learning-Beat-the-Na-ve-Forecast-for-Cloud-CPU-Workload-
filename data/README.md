# `data/` — raw traces and everything built from them

*Bản tiếng Việt ở nửa dưới.*

Nothing in this directory is tracked by git except this file: the raw traces are about
11 GB and what the pipeline builds from them is another 30 GB. Everything here is either
downloaded from a public archive or regenerated by the code in this repository.

## What you must download

Place the two public traces exactly like this:

```text
data/raw/Bitbrains-fastStorage/08-2013/*.csv      1,250 CSV files, ~1.2 GB
data/raw/Bitbrains-Rnd/2013-7/*.csv               500 CSV files
data/raw/Bitbrains-Rnd/2013-8/*.csv               500 CSV files
data/raw/Bitbrains-Rnd/2013-9/*.csv               500 CSV files   (Rnd total ~1.1 GB)
data/raw/Alibaba-Cluster-Trace/machine_usage.csv  one file, ~9 GB, no header row
```

- Bitbrains, GWA-T-12 (TU Delft): <http://gwa.ewi.tudelft.nl/datasets/gwa-t-12-bitbrains>
- Alibaba cluster trace v2018: <https://github.com/alibaba/clusterdata/tree/master/cluster-trace-v2018>

The Bitbrains CSVs use `;` plus a tab as the separator and carry a header row. The Alibaba
file has **no** header; the pipeline supplies the column names, and reads only the first
three columns. Only `CPU usage [%]` and `cpu_util_percent` are used as the target, both on
a 0–100 scale, which is what makes the three environments comparable at all.

Experiment B needs all three Rnd months. If you only want to reproduce Experiment A, the
August month is enough.

### If you already have the traces elsewhere

Do not copy 11 GB. Point at the existing copy instead:

```powershell
# Windows, from the repository root
New-Item -ItemType Junction -Path data\raw -Target "X:\path\to\raw"
```

```bash
# Linux or macOS, from the repository root
ln -s /path/to/raw data/raw
```

|---|---|---|

| `features/` | K2.2, K2.3, K6.1, K7.2 | 2.2 GB |
| `eval_rows/` | K2.5, K6.1, K7.2b | 52 MB |
| `k0/` | K3 | 366 MB |
| `nguong_0p0/`, `nguong_0p5/`, `nguong_2p0/` | K7.5 | 1.1 GB total |

Once these exist you can check them against ours without training anything:

```bash
python scripts/van_tay_du_lieu.py
```

# `data/` — dữ liệu thô và mọi thứ dựng từ nó

Thư mục này không có gì được git theo dõi ngoài chính tệp bạn đang đọc: dữ liệu thô khoảng
11 GB, và những gì đường ống dựng ra từ nó thêm khoảng 30 GB nữa. Mọi thứ ở đây hoặc tải về
từ kho công khai, hoặc do mã trong kho này sinh lại.

## Thứ bạn phải tự tải

Đặt hai tập vết công khai đúng cấu trúc đã ghi ở phần tiếng Anh phía trên.

Tệp CSV của Bitbrains dùng dấu phân cách là `;` kèm một ký tự tab và **có** dòng tiêu đề.
Tệp Alibaba **không** có dòng tiêu đề; đường ống tự cấp tên cột và chỉ đọc ba cột đầu. Chỉ
`CPU usage [%]` và `cpu_util_percent` được dùng làm giá trị cần dự đoán, cả hai trên thang
0–100 — chính điều này làm cho việc so sánh ba môi trường trở nên hợp lệ.

Thí nghiệm B cần cả ba tháng của Rnd. Nếu bạn chỉ muốn dựng lại Thí nghiệm A thì riêng
tháng 8 là đủ.

### Nếu bạn đã có dữ liệu thô ở chỗ khác

Đừng chép 11 GB. Trỏ sang bản có sẵn:

```powershell
New-Item -ItemType Junction -Path data\raw -Target "X:\duong\dan\raw"
```

## Thứ đường ống dựng ra ở đây

Xem bảng ở phần tiếng Anh. Khi đã có, bạn kiểm được chúng với bản của chúng tôi mà không
cần huấn luyện gì:

```bash
python scripts/van_tay_du_lieu.py
```
